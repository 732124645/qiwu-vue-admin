# 栖梧 Qiwu 视觉规范 ·「远洋」

> 本文是界面的唯一视觉依据；实现只通过设计令牌生效，组件里不写裸色值。

## 1. 气质

稳重、大气、正规：深海军蓝侧栏把导航与内容明确分开，浅灰画布上的白色卡片承载内容，层次靠留白与柔和阴影，蔚蓝主色只用于"要用户注意/可操作"的地方。

侧栏外观可独立选择深色或浅色，默认深海军蓝；选择保存在当前浏览器，旧设置自动补默认值。浅色变体的 `--qw-side-light-*` 在全局亮/暗主题中分别引用当前的 `--qw-surface`（底色）、`--qw-text-2`（正文）、`--qw-text-3`（辅助文字）、`--qw-brand-weak`（悬停与当前分组底）与 `--qw-text`（悬停文字、字标）。`.qw-side-light` 只作用于侧栏或窄屏菜单抽屉，顶部/混合导航条仍用海军蓝；选中项仍是 `--qw-brand` 实心底配 `--qw-side-active-text` 白字。分组强调与展开箭头使用 `--qw-side-hover-text`，字标使用 `--qw-side-logo-text`，避免浅底白字。对比度检查覆盖两套全局主题、两种侧栏外观、全部预设与校准后的自定义主题色，正文（含字标后缀）≥ 4.5:1，图标（含透明度合成）≥ 3:1；浏览器用例另核对实际作用域颜色、悬停/选中态与持久化。

主题色可在设置抽屉切换：切换时改 `--qw-brand`（自定义颜色若白字对比不足 4.5:1，先按 2% 步长加深到恰好达标，选色器显示校准后的值：`core/theme.ts` `brandFill`），并按亮度派生 `--qw-brand-text`（亮色加深、暗色提亮，直到对画布、表面、次级表面与浅底都 ≥ 4.5:1）、`--qw-brand-weak` 与 Element Plus 主色阶，其它令牌不变。

**为什么拆成两个主色令牌**：暗色表面上，没有任何一种蓝色能同时满足"白字在其上 ≥ 4.5:1"（要求亮度 ≤ 0.18）和"作为文字在暗色表面上 ≥ 4.5:1"（要求亮度 ≥ 0.21）。填充与文字因此分别取值；亮色下两者相同。

## 3. 与 Element Plus 的映射（`apps/web/src/styles/element.css`）

- `--el-color-primary` ← `--qw-brand`（填充）；暗色下链接、文字按钮、`el-link`、`el-tabs`/`el-menu` 选中文字等以主色作文字的组件改用 `--qw-brand-text`；`light-3/5/7/8/9` 与 `dark-2` 按主色混合生成（亮色混白、暗色混画布色），切换主题色时同步重算。
- `--el-color-success/warning/danger/info` ← 对应语义令牌。
- `--el-bg-color` ← `--qw-surface`，`--el-bg-color-page` ← `--qw-canvas`，`--el-fill-color-light` ← `--qw-surface-2`。
- `--el-border-color` / `-light` / `-lighter` ← `--qw-border` 系列。
- `--el-text-color-primary/regular/secondary/placeholder` ← `--qw-text` / `-2` / `-3`。
- `--el-border-radius-base` ← `--qw-radius-sm`；`--el-box-shadow-light` ← `--qw-shadow-1`；`--el-box-shadow` ← `--qw-shadow-2`；`--el-font-family` ← `--qw-font`；`--el-font-size-base` 14px。
- 组件微调只写在这一个文件：表头底色与字色、行高、按钮字重 600、对话框圆角与内边距、输入框底色、下拉阴影。

## 4. 布局

- **侧栏**：宽 220 / 折叠 64；底色 `--qw-side-bg`，暗色或浅色侧栏加 1px 右边线（顶部/混合布局的导航条加底边线）；顶部 Logo 区高 56（渐变方标 + 产品名，字色随侧栏外观）；所有层级的分组都是可折叠菜单（图标、标题、展开箭头），默认只展开当前页面路径上的分组，切换页面时展开新路径并保留用户手动展开的其他分组；嵌套层级逐级缩进；菜单项高 40、圆角 8、左右内缩 10；选中项实心主色，当前路径的分组以悬停底与 `--qw-side-hover-text` 强调；图标 16px 线性。
- **头部**：高 56，白色（暗色为表面色），底部 1px 边框；左侧折叠按钮 + 面包屑（末级加粗）；右侧菜单搜索胶囊（带快捷键提示）、全屏、尺寸（密度图标 `rows-3`）、语言、头像菜单。
- **标签栏**：高 40，胶囊标签，选中为主色浅底 + 主色字；右键菜单沿用现有功能。
- **内容区**：画布色，内边距 20–24；标签栏和面包屑标明当前页面，不另设页面标题与说明；子页面少量页面级操作放在右对齐的 `.qw-page-bar`；搜索面板与表格面板为两张独立卡片，区块间距 16。
- **搜索面板**：筛选项排成等宽网格（每格最少 224px，间距 16/24），搜索与重置在最后一格、贴右；1280 宽下三个筛选项加按钮仍是一行。
- **顶部 / 混合布局**：同一套令牌；顶部布局的导航条用侧栏深色。

## 5. 组件规则

- **表格**：表头 `--qw-surface-2` 底、12px 次要文字、字距 .02em，表头与操作列不换行；行高 48；单元格左右 16；斑马纹关闭，悬停行用 `--qw-surface-2`；数字等宽、右对齐；排序箭头小号、`--qw-text-3` 半透明，仅当前方向用主色文字；状态用胶囊（圆点 + 文字，语义色浅底），可切换时用小号开关；操作列文字按钮（编辑为主色、删除为危险色），默认宽 140；短列定宽（按最长语言的表头 + 排序箭头），只让备注这类自由文本列伸缩并放在最后；工具栏左侧主操作、右侧刷新与列设置图标按钮（带可读名称，开关按下态同悬停态，不用主色）；批量操作只在选中行后出现。
- **分页**：总数在左（辅助文字色），每页条数与页码在右；无数据时不显示，一页最小条数（10）放得下时只显示总数，超过 7 页才出现跳页；上一页/下一页透明底。
- **空状态**：无筛选时"暂无数据"；带筛选条件查无结果时"没有符合条件的结果" + 提示 + "清空筛选"按钮（`QwTable :filtered`）。
- **加载**：表格遮罩上 28px 细圈（主色文字色）；首次加载骨架行待定。
- **表单**：标签在上或左对齐（弹框内左对齐，宽度自适应最长标签、最少 96px、不换行：CSS 网格 + subgrid，所有输入框同一起点）；输入框底 `--qw-surface-2`，聚焦时主色 2px 外发光；数字框右侧步进时数字左对齐；必填星号用危险色（由 zod 规则推出：既不接受空值也不接受空串即必填；登录、锁屏、改密等全必填的页面不显示）；错误文案在字段下方；文本域字数统计避开拖拽角。
- **按钮**：主按钮实心主色，一屏只一个（列表页是"新增"），悬停/按下时与黑色混合加深（88% / 80%，不混白，白字始终 ≥ 4.5:1，contrast 测试覆盖两套主题与全部预设色）；搜索用主色浅底按钮（悬停加深浅底，不变实心）；次按钮（重置、取消）白底边框；幽灵按钮无边框；高度 32（默认尺寸）；字重 600；加载态禁用。
- **弹框**：圆角 `--qw-radius-lg`，阴影 `--qw-shadow-2`（暗色另加 1px `--qw-border` 边框，弹框、消息框、抽屉同）；头部 18px 标题 + 分隔线，底部右对齐按钮；遮罩 `rgba(8,13,22,.45)` 并轻微模糊。
- **空状态**：统一 `EmptyState` 组件（原创线稿 SVG + 标题 + 说明 + 可选主操作），用于表格无数据、搜索无结果、无权限。
- **标签 / 状态胶囊**：`DictTag` 统一为胶囊样式，按字典 `tag_type` 映射语义色。

## 6. 登录页

左右分栏（≥ 992px）：左侧品牌区为海军蓝渐变 + 淡网格纹理（CSS 绘制，无图片），产品名、一句定位、三条卖点；右侧白色表单区居中。窄屏只显示表单区，品牌区收成顶部色带。语言切换在右上角。

实现（`core/layout/AuthPage.vue`，登录、锁屏、强制改密、SSO 授权页共用）：品牌区宽 `clamp(420px, 44%, 680px)`、左右内边距 `clamp(56px, 5vw, 96px)`、标语 `clamp(32px, 2.4vw, 44px)`，右侧表单宽 400、略高于垂直居中；登录的"记住用户名""保持登录"并排在左，右侧留给以后的"忘记密码"；标题 26px/650 + 一行副标题（登录欢迎语、锁屏提示、改密的密码规则、SSO 的当前账号）。< 992px 色带与表单卡片同一列（卡片最宽 420，上移 56px 压在色带上），语言切换与卡片右缘对齐。

## 7. 首页

欢迎横幅（问候 + 部门与角色 + 上次登录时间），下方工作计数与快捷入口卡片（按用户已授权的菜单生成）。首页不放假数据。

实现（`views/home/index.vue`）：问候按本地时间分早上/下午/晚上，横幅右上角用主色网格纹理呼应登录页；快捷入口即侧栏可见的全部页面（外链新窗口打开，分组名作副标题、最多两行并带完整提示；种子菜单没有描述字段，不另编说明），网格 `auto-fit`、每格最少 280px、最多 4 列，卡片右缘与横幅对齐；一个都没有时显示 `EmptyState`。横幅的"上次登录"取 `/me` 的 `lastSignInAt`（本会话之前最近一次成功登录；首次登录不显示）。横幅与快捷入口之间是工作计数：我的待办、审批中的申请（有审批中心页面时才显示）与未读消息，每格一个图标、标签和数字（未取到时为"–"），点开对应列表；网格 `auto-fill`、每格最少 220px、最多 3 列，静止时无阴影（同快捷入口）。

## 8. 动效

- 时长：悬停与颜色 150ms；展开/抽屉/弹框进入 220ms、退出 160ms；路由切换淡入 + 4px 上移 180ms。
- 缓动：进入 `cubic-bezier(.2,.8,.2,1)`，退出 `cubic-bezier(.4,0,1,1)`。
- `prefers-reduced-motion: reduce` 时去掉位移与缩放，只保留瞬时切换。

## 9. 无障碍

- 正文与背景对比度 ≥ 4.5:1，大字与图标 ≥ 3:1，亮暗两套都校验（自动化检查：`pnpm --filter @qiwu/web test contrast`）。
- 焦点环 2px 主色、2px 偏移，任何可交互元素可见。
- 图标按钮都有 i18n 的 `aria-label`；侧栏折叠后菜单项有提示。

## 10. 图标

线性图标统一一套（描边 1.8、圆角端点），菜单、按钮、空状态风格一致。候选：Lucide（ISC，经 `@iconify-json/lucide` 离线使用）替代 Element Plus 自带图标集，以获得更精致的线性风格；许可证白名单已含 ISC。

### 品牌标志 · Nested Tile

- **构成**：圆角方形渐变底座内是一条右上角开放的圆角框，开口旁放一枚小方形模块。底座、框与模块均为原创几何；框和模块使用白色或 `currentColor`。界面中的底座沿用 `BrandMark` 的 `--qw-brand` 主题渐变、圆角和内环，因此随用户选色变化。
- **名称**：显示名中文 **栖梧**、英文 **Qiwu**，取"凤栖梧桐""良禽择木而栖"——做一棵值得栖息的梧桐，logo 巢格即梧桐上的巢。项目名 `qiwu-vue-admin`；内部名称随之改为 `@qiwu/*` / `Qw*` / `--qw-*` / `qw:`。
- **字标**：界面里用可翻译的实时文字（`common.app.name` + `common.app.suffix`）。zh-CN 为 `栖梧管理系统`，`栖梧` 字重 600，`管理系统` 字重 400、约 60% 不透明度，两段之间不留空格，整体字距约 0.04em（按 `:lang(zh)` 生效，后缀同距）；en-US 为 `Qiwu Admin`，`Qiwu` 字重 600，` Admin` 字重 400、约 60% 不透明度，略增字距。两种语言主次一致，与浏览器标题的品牌名相同。`docs/design/brand/` 中的亮暗 SVG 锁定组合供文档复用：`wm-qiwu-light.svg` / `wm-qiwu-dark.svg`（Qiwu）、`wm-qiwu-admin-light.svg` / `wm-qiwu-admin-dark.svg`（Qiwu Admin）、`wm-qiwu-zh-light.svg` / `wm-qiwu-zh-dark.svg`（栖梧管理系统）；界面不使用图片字标。
- **留白与尺寸**：标志四周至少留出底座边长的 0.25 倍净空。底座最小 16 px；20 px 及以下使用 `favicon.svg` 的加粗提示几何（描边 3），较大尺寸使用 `mark-mono.svg` 的描边 2.5。
- **颜色**：界面底座取主题 `--qw-brand`，框和模块取 `--qw-on-brand`；文档 SVG 的底座为固定品牌蓝渐变。字标用所在表面的文字令牌，侧栏或海军蓝背景用 `--qw-side-logo-text`。浏览器 favicon 使用固定品牌蓝。
- **正确使用**：保持开放角、小方块、留白和比例，浅色与深色背景选对应字标。**不要**封闭开口、挪动模块、扭曲比例、给图形添加描边/阴影，或把固定蓝 SVG 放进可换主题色的界面底座。

## 11. 不做

外部字体、玻璃拟态、大面积渐变背景（移动端登录页与 tab 页头部例外，见 §12.7）、emoji 图标、每个区块都加阴影、页面加载时的大段编排动画。

## 12. 移动端（`mobile/`）

> 移动端整体视觉采用"梧桐 · 远洋"：登录页用梧桐插画 + 贴底白色底板、海军蓝背景；tab 页是海军蓝头部 + 夜色梧桐插画；支持浅色与深色。移动端沿用 §1–§10 的令牌、语义色、品牌标志与无障碍规则，本节只写移动端的增量与例外。

### 12.1 令牌

定义在 `mobile/src/App.vue` 的 `page, .wd-root-portal`，`--wot-*` 只指向 `--qw-*`。与 web 同名的令牌在浅色、深色下都取 §2 的值（`mobile-theme.spec.ts` 对照 `apps/web/src/styles/tokens.css` 校验）；web 已有、移动端补上 `--qw-side-hover` 与 `--qw-ease-enter`（§8 的进入缓动）。唯一的例外：`--qw-side-text` 在深色下仍取浅色值 `#B9C4D8`——它所在的海军蓝头部与登录背景不随主题变化，web 的深色值 `#9FACC2` 在头部主色光晕上只有 4.04:1（§12.6）。只在移动端新增（web 不加）：

| 令牌                                                                    | 浅色                                   | 深色             | 用途                                                                          |
| ----------------------------------------------------------------------- | -------------------------------------- | ---------------- | ----------------------------------------------------------------------------- |
| `--qw-brand-2`                                                          | `#2193E0`                              | 同               | 标志渐变的青色端（同 `docs/design/brand/mark.svg`）：标志块、头像、公告图标块 |
| `--qw-brand-soft`                                                       | `#A9C7F7`                              | 同               | 插画中间调（远叶、雾线、夜色鸟身）；不用于文字和控件                          |

### 12.2 使用规则

- 尺寸用 rpx（750rpx = 屏宽）；触控目标 ≥ 44pt（tab 54、列表行 ≥ 64、菜单行 56、按钮 48/52、分段每格 44、"全部 ›"等文字链热区 44）。
- 圆角：`radius-sm` 8 = 复选框；`radius` 10 = 意见气泡、提示条、32 图标块、分段选中块；`radius-lg` 14 = 卡片、带边框输入框、按钮（48/52 高）、40/48 图标块、分段轨道；`radius-xl` 24 = 底板与底部弹层。几何形状照写：胶囊、头像、角标 `999px` / `50%`，标志块 `30%`（同 web `BrandMark`）。卡片圆角比 web 大一档。
- 字号只用 `--qw-fs-*`（输入框 `body-lg`，≥ 16px，H5 上 iOS 聚焦不放大）；字重只用 400 / 500 / 600 / 650；数字 `font-variant-numeric: tabular-nums`。
- 颜色只用令牌；透明度用元素 `opacity` 或 SVG `stop-opacity`，不用 `color-mix()`（老安卓 WebView 与部分小程序基础库不支持）。字面量颜色只有两处例外，都由 `mobile-theme.spec.ts` 断言等于对应主题的令牌值：`pages.json` / `theme.json`（原生导航栏只收字面量）与 `static/` 下烘焙过颜色的 SVG（小程序 `<image>` 读不到 CSS 变量）。
- 深度：卡片默认无阴影；只有工作台计数卡（`--qw-shadow-1`）、详情操作栏（`--qw-shadow-up`）、弹层（`--qw-shadow-2`）有深度。

### 12.3 页面结构

- **tab 页**（工作台、审批、消息、我的；`QwPageHeader`）：`--qw-side-bg` 实底 + 右上一团 `--qw-brand` 径向光（不透明度 .5，只在头部内）+ 右侧夜色梧桐插画（工作台、我的带鸟，审批、消息只有枝叶）；内容左对齐——工作台：标志 + 字标、问候、部门·角色；审批、消息：大标题 + 一行摘要（"5 项待你处理""3 条未读"）；我的：头像 64 + 姓名 + 用户名 + 部门、角色胶囊。状态栏白字；小程序的标题行与胶囊按钮同一行、右侧让出胶囊宽度。头部底部多留 24px，由**底板**压住：`--qw-canvas`、上圆角 `radius-xl`、`margin-top: -24px`。
- **子页**：原生导航栏（浅色白底黑字，深色表面色白字），画布 + 卡片，不放插画。
- **登录**：整屏 `--qw-side-bg` + 右上主色径向光（.5）+ 底部向主色渐淡；上部品牌区是放大的夜色梧桐插画、只在中文显示的竖排题款"良禽择木而栖"、标志 52 + 字标 + 一行标语，没有可点的东西；下部贴底底板（`--qw-surface`，上圆角 `radius-xl`）：标题式选项卡（选中 `title-lg`/650 + 主色短横条）、52 高输入框与主按钮、记住用户名、页脚（语言 · 版本 · 隐私政策 · 用户协议）。语言切换放页脚，三端位置一致，避开小程序右上角胶囊。键盘弹起或窗口高 < 700 时收成紧凑头部（插画按右上角缩到 0.46，标志 36 + 字标同一行，题款、标语隐藏）；欢迎语与页脚只在键盘弹起时隐藏——矮屏上照常显示，因为语言切换只在页脚；微信绑定页用紧凑头部。
- **启动图（App）**：海军蓝 + 夜色梧桐 + 标志字标；安卓 12+ 系统启动层底色 `--qw-side-bg`。小程序没有自定义启动图。
- **App 图标**：品牌蓝渐变底座 + 白色 Nested Tile（§10），1024 不透明、无圆角（系统加遮罩）；微信小程序头像在公众平台后台上传。

### 12.4 组件

- **列表行**：左 40 头像（发起人首字，4 种底色按用户 id 取模：brand / success / warning / neutral 的浅底 + 对应文字色）或 40 图标块；标题 `body-lg`/600 单行省略，右侧短时间（今天 `HH:mm`、今年 `MM-DD HH:mm`、更早 `YYYY-MM-DD`；详情仍用完整时间）`caption` `--qw-text-3`；第二行 `body` `--qw-text-2`（"李娜 发起 · 总监审批"）。审批列表一行一张卡；消息与工作台"待我审批"是分组卡（行间 1px 分隔线，从文字起点开始）。
- **状态胶囊**：高 22、`999px`、12px/500、前置 6px 圆点；语义色浅底 + 语义色字，按字典 `tag_type` 映射（同 web `DictTag`）。已办列表：我的处理结果用胶囊，流程状态用文字"流程 · 审批中"。
- **计数**：tab 角标与未读红点 `--qw-danger` + 2px 表面色描边；分段里的待办数用 `--qw-brand` 小胶囊；工作台计数卡三格（待办 / 审批中 / 未读消息），数字 `display`/650，标签前置彩色线性图标。
- **分段筛选**（替换 `wd-tabs`）：轨道 `--qw-neutral-weak`、`radius-lg`、每格 44 高；选中块画在格内 3px，`--qw-surface` + `radius` + `--qw-shadow-1`，600 字重。
- **按钮**：48 高（登录 52）、`radius-lg`、`body-lg`/600。主按钮实心主色 + `--qw-shadow-brand`；危险次按钮表面色底 + 1px `--qw-danger` 描边红字；柔和按钮 `--qw-brand-weak` 底 `--qw-brand-text` 字；图标按钮（"更多"）图标在上、`micro` 文字在下，宽 52。
- **详情操作栏**：表面色底 + `--qw-shadow-up` + 安全区；`[更多][驳回 flex 1][通过 flex 1.5]`。
- **时间线**（替换 `wd-steps`）：36 圆形头像（操作人首字）+ 右下 16px 动作角标（通过 = 绿底勾、驳回 = 红底叉、退回 = 橙底回箭头、发起 = 蓝底纸飞机）；节点间 2px `--qw-border` 竖线；意见放 `--qw-surface-2`、`radius` 的气泡；"轮到我"的节点画成主色描边头像 + "待处理"胶囊。
- **tab 栏**：表面色底、顶边 1px `--qw-border`，高 54 + 安全区；自绘 4 个线性图标（工作台 = Nested Tile 开口框 + 小方块，审批 = 单据勾，消息 = 气泡，我的 = 人像），描边 1.8；选中描边 `--qw-brand-text` + 内部填 `--qw-brand-weak`、文字 600。
- **空状态 `QwEmpty`**：220×160 插画（同一棵梧桐，闭眼休息的鸟）+ 标题 `title`/600 + 说明 `body` `--qw-text-3` + 可选柔和按钮；`z-paging` 与原 `wd-empty` 处都用它。
- **我的**：分组菜单行高 56、左 32 彩色图标块；退出登录是一张卡片、居中红字；底部"标志 · 栖梧 · 版本"。

### 12.5 插画

一套原创 SVG（梧桐枝、三裂叶、长尾鸟、圆盘、雾线；不取自任何模板或生成图），两种配色，导出到 `mobile/src/static/` 后用 `<image>` 显示、`aria-hidden`：

- **夜**（海军蓝上：启动图、登录、tab 页头部）：圆盘 `--qw-brand` 20%、枝 `--qw-brand-soft` 42%、近叶 `--qw-brand`、远叶 `--qw-brand-soft` 55%、鸟身 `--qw-brand-soft` + 翅 `--qw-brand`。深底上的鸟必须是浅色。
- **日**（浅色表面上：空状态）：圆盘 `--qw-surface`、枝与鸟身 `--qw-side-bg`、近叶 `--qw-brand`、远叶与雾线 `--qw-brand-soft`。

### 12.6 深色

- **切换**：默认跟随系统；App 与 H5 在"我的 → 外观"可选跟随系统 / 浅色 / 深色（存本地、即时生效）；微信小程序只跟随系统，不显示该项。
- **令牌**：同名令牌取 §2 暗色值（`--qw-brand` 与 `--qw-brand-text` 分开取值的规则照旧）；`--qw-side-bg` 两种主题相同，所以 tab 页头部、登录背景、启动图与夜色插画不随主题变化。
- **分层**：深色下卡片、tab 栏、操作栏靠 `--qw-border` 边线分层，阴影令牌除 `--qw-shadow-2` 外为 `none`（同 §2）；底板与海军蓝头部靠色相区分（同 §2 注 ²）。
- **静态资源**：烘焙颜色的 SVG 在表面上显示的（tab 图标、空状态）按主题各一份，只含该主题的令牌色；深色空状态用夜色配色。原生导航栏颜色写在 `theme.json`。
- **状态栏**：登录与 tab 页始终白字；子页随主题。
- **对比度**：亮暗两套都满足 §9（正文 4.5、大字与图标 3），由 `mobile-theme.spec.ts` 的 contrast 用例按 WCAG 公式校验。实测（浅色 / 深色；弱色底与 rgba 令牌叠在表面色上，光晕取峰值：海军蓝上叠 50% 主色）：
  - 正文：`--qw-text` 在画布 15.84 / 16.55、表面 17.46 / 15.39、`surface-2` 16.55 / 14.48、`--qw-raised` 17.46 / 10.36；`--qw-text-2` 在画布 6.51 / 8.00、表面 7.17 / 7.44、分段轨道 6.33 / 6.27；`--qw-text-3` 在画布 4.89 / 5.36、表面 5.38 / 4.99、`surface-2` 5.10 / 4.69。
  - 主色：`--qw-brand-text` 在表面 5.15 / 7.20、画布 4.68 / 7.74；`--qw-on-brand` 在 `--qw-brand` 4.63（两种主题同）。
  - 海军蓝（两种主题同）：白字 17.36、光晕峰值上 9.26；`--qw-side-text` 9.88、光晕峰值上 5.27。
  - 渐变（标志块、公告图标块、"我的"头像）：白色在 `--qw-brand-2` 端 3.33——只放图标与 ≥ 18.7px 粗体的大字（头像首字 48rpx/600）。
  - 状态胶囊（字色 / 弱色底）：主色 4.53 / 5.95、成功 4.51 / 7.09、警告 4.67 / 6.99、危险 4.65 / 5.26、中性 4.75 / 5.23；角标数字（表面色 / `--qw-danger`）5.31 / 6.10；未读红点在表面 5.31 / 6.10、画布 4.82 / 6.56。

### 12.7 与 §11 的例外

§11"大面积渐变背景"对移动端两处开例外：登录页整屏海军蓝上的径向光与底部渐淡，tab 页头部的径向光（限于头部内，约占屏高 22%）。两处都是低不透明度的光，底色仍是实心海军蓝；子页、弹层、卡片不用渐变背景，§11 其余各项不变。

### 12.8 动效与读屏

- 选项卡字号与颜色 150ms；底板随键盘升降、插画缩放 250ms（`--qw-ease-enter`）；`prefers-reduced-motion` 时全部瞬切；tab 页头部与底板无动画。
- 插画、题款、标志 `aria-hidden`；选项卡与分段 `tablist` / `tab` / `aria-selected`；未读红点与 tab 角标随名称读出（"审批，5 项待办"）；图标按钮有可读文字。
