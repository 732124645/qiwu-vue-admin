# ADR-002 — ORM: TypeORM under ESM

- Status: accepted
- Date: 2026-09-26

## Context and decision

Use TypeORM 1.1.1 with MySQL, `@nestjs/typeorm`, CLS transactions and the TypeORM transactional adapter. A single DataSource configuration is shared by Nest, compiled database commands and tests. `synchronize` remains false; schema changes use migrations.

The integration checks exercised circular relations, migration run/revert, soft-delete uniqueness, audit columns, scoped queries and locks, rollback, and information_schema metadata. These contracts are covered by the [database tests](../../apps/server/test/core/core-db.spec.ts), [migration tests](../../apps/server/test/db/db-migrations.spec.ts) and [data-scope tests](../../apps/server/test/e2e/data-scope.e2e-spec.ts).

## Technical findings

- mysql2's `timezone: 'Z'` converts JavaScript dates but does not set the database session zone. Each pooled connection runs `SET time_zone = '+00:00'` before queries so database-defaulted timestamps also use UTC.
- Subscribers require `@EventSubscriber()` even when listed explicitly; otherwise TypeORM does not instantiate them and audit fields remain empty.
- Use `Relation<T>` for relation property types. It avoids reading a related class during decorator metadata emission, which can fail in an ESM import cycle.
- Raw-query pessimistic locks do not enforce a transaction themselves. `lockScopedIds` checks for an active transaction before acquiring row locks.
- Soft-delete uniqueness uses a generated `alive` column in unique indexes. The column is not mapped as an entity property; deleted values can be reused while live duplicates are rejected.

## Consequences

Business services use the transaction-bound repository and shared data-scope helpers. Reads, options and exports use `scopedQb`; writes lock scoped ids and check writable values. Compiled migration and seed commands run with cwd `apps/server`, loading secrets from `.env.local` and non-secret configuration from `.env`; process environment takes precedence.

See [data-scope design](../design-notes.md#data-scope), [data-scope integration](../data-scope.md) and [environment isolation](../getting-started.md#2-空库账号与隔离).
